# BTR 目标检测代理 `btr_detect_agent.py`

输入一次仿真的两张方位历程图 (舷侧阵 `hull` + 拖曳阵 `tow`)，快速给出每个目标的
**初始/结束位置、舷角偏转、距离 (含 CPA)**，并自动与生成端真值逐项对比、定级。

## 快速开始

```bash
# 最简: 平台参数从同目录 btr_*_track.txt 自动读取
python btr_detect_agent.py --hull-img btr_out\20261105_152635\btr_A_hull.png ^
                           --tow-img  btr_out\20261105_152635\btr_A_tow.png

# 显式指定平台/阵列参数
python btr_detect_agent.py --hull-img a\btr_A_hull.png --tow-img a\btr_A_tow.png ^
    --start-ll 30.0 122.0 --heading -30 --speed-kn 0 --tow-m -180 0

# 同时导出 JSON / 叠加核验图 / 文本报告
python btr_detect_agent.py --hull-img ... --tow-img ... ^
    --json out.json --png out.png --report out.txt
```

## 参数

| 参数 | 说明 |
|---|---|
| `--hull-img` / `--tow-img` | 两张 BTR 图 (必填, PNG) |
| `--start-ll` `--heading` `--speed-kn` | 平台起点经纬度 / 航向 (北=0°顺时针) / 航速 (kn) |
| `--hull-m` `--tow-m` | 舷侧阵 / 拖曳阵相对船体的偏移 (m, x>0 船头, y>0 左舷) |
| `--track-txt` | 平台参数来源; 缺省自动找同目录 `btr_*_track.txt` |
| `--level` | 等阈电平 (dB); 缺省按数据自适应 |
| `--dt` | 提取时间步长 (s), 默认 2 |
| `--side` | `auto` (按代价选左右舷) / `pos` / `neg` |
| `--cmap` | `auto` / `gui` / `geo` (生成端配色) |
| `--no-truth` | 不与真值对比 (无同目录 txt 时) |
| `--json` `--png` `--report` | 三种可选输出 |

优先级: 命令行显式参数 > 同目录 `track.txt` > 默认值。**任何平台参数没解析出来都会
显式报警告**，不会静默用默认值污染对比结果。

## 输出

- 终端: 逐目标明细 (起止位置/舷角/距离/CPA/运动段速度航向) + 与真值差异 + 汇总表
- `--json`: 结构化结果 (标定、每目标每分支、真值差异全字段)
- `--png`: 叠加核验图 (原图+检出轨迹、检测 vs 真值平面、距离-时间)
- `--report`: 文本报告落盘

## 质量等级

汇总表按 **方位残差 RMS** 与 **位置中位误差** 给每个目标定级：

| 级 | 判据 | 含义 |
|---|---|---|
| A | RMS ≤0.5° 且 位置 ≤1 km | 可直接用 |
| B | RMS ≤2° 且 位置 ≤3 km | 趋势可信，绝对量宜复核 |
| C | RMS ≤5° | 仅相对量 (舷角/偏转) 可信 |
| D | 其余 | 不可用 (轨迹合并 / 平台模型不符) |

失准时会附诊断: 交叉合并风险、真值漏检清单、亮带覆盖率过低、平台航点模型不符等。

## 方法要点 (与 `btr_infer_track.py` 的区别)

`btr_infer_track` 走批量匀速直线 Gauss-Newton 拟合；本代理针对
**平台静止 / 目标走完航点后方位恒定** (距离不可观) 的场景，改用:

1. **轴自标定** — 自动定位绘图区 (剔色标条)，用灰色网格线反推刻度并校验
   (报告 0° 原点偏移，正常 <0.1°)。
2. **等阈亮带亚像素中点定方位** — 亮线饱和时峰值检测会锁到平台右缘 (可偏 +5°)；
   亮带两缘对称于真实方位，削顶不影响中点。电平按数据自适应 (min 两阵 p99.9 − 2.5)，
   **两阵共用一个电平** (否则短基线视差被放大成百分之十几的距离误差)。
3. **双站视差交会定距** — 同历元 hull/tow 舷角交会；视差 <0.35° 的历元丢弃 (发散)，
   距离做中值平滑。
4. **通道分解速度** — 切向 = r̄·dθ/dt (方位通道精确)，径向 = dr/dt
   (仅单历元距离回归显著才采用，否则置 0，避免假径向速度把航向带偏)。
5. **左右舷** — 两阵共线于艏艉线时镜像不可分辨，两支都报，有真值则按位置误差判定。

## 已知边界

- 距离精度受基线限制: 180 m 基线在 10 km 量级上单历元 σ≈1 km，平滑后约 ±3~10%。
- 平台若按航点折线运动 (航向随时间变)，绝对位置/距离会有系统偏差 (会显式警告)；
  此时方位/偏转/视差等相对量仍可信。
- 两目标方位间距小于亮带宽度时会被跟迹合并 (汇总表标交叉风险 + 漏检清单)。
