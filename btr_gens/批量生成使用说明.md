# BTR 批量生成

## 启动与操作

在本目录执行 `python btr_gui_server.py`，浏览器打开 http://127.0.0.1:8765 。
升级代码后必须停止原来的 Python 服务并重新启动，仅刷新页面不会更新后端。

页面右侧地图下方新增“批量生成”区域：设置样本数（1～1000）、模式、随机种子、扰动百分比，点击开始。
样本数指仿真次数；有多个平台时，每次仿真为每个平台生成一组图。

三种模式：
- noise：使用当前配置，只改变每样本的噪声种子；路径不变。
- perturb：在当前配置上，噪声、杂波、强度、宽度和航点路径航速按±百分比缩放；航向改变±(30°×百分比)，航点路径起点和全部航点整体平移，每坐标±(0.01°×百分比)。曲线公式不修改；平台起点、目标数、出现/消失时间不变。零值参数仍为零。
- scenarios：复用 gen_train_ds.py 的 S01～S16 build_payload，顺序轮换；32个样本对应每类2次。使用预设600秒和1秒步长，忽略左侧配置。场景标签是生成意图，尚未调用旧脚本的CPA重试/验收流程，不保证每个样本符合全部场景标签。

停止按钮会等待当前样本完成，保留结果、不开始下一个。一个服务同一时间只接受一个活动批次；绘图与单次运行共用锁，不能并行渲染。
刷新页面可以继续查询同一服务内的任务。服务重启不会自动恢复/续跑；请查看磁盘manifest，进程中断时其中可能仍为running。
同一配置、种子和运行环境可复现数值；时间戳、目录、TXT生成时间及其哈希不保证相同。

```
batch_.../
  batch_config.json          用户配置与模板（含真值，请勿盲测上传）
  manifest.json              状态、样本索引、文件SHA256
  model_inputs.jsonl         仅成功样本的图片和平台信息相对路径
  sample_0001/
    input/
      btr_A_hull.png          无白/黄真值参考线
      btr_A_tow.png
      platform.json          已知平台参数、时间/角度轴、左右模糊说明
    truth/
      btr_A_track.png
      btr_A_track.txt
      btr_A_hull.txt
      btr_A_tow.txt
      btr_A_truth.jsonl       每有效时刻的真实位置、阵列方位与距离
    meta.json                实际生成参数、随机种子、完成/失败状态
    semantic.json            按用户提供Schema生成的完整语义参考数据
```

多平台时文件按平台名分别保存。真值JSONL包含：platform_id、target_id、time_s、lat/lon、platform_lat/lon、hull/tow_bearing_deg、hull/tow_range_m、depth_m=null、source=simulation_truth。
位置从全局t=0运动，仅在目标出现/消失窗口内导出。时间采样不超过T_MAX；DT不整除时不强制补终点。
真值不是识别散点；CSV散点生成、深度模拟、断续亮线等本次不新增。

## 模型使用边界

只将input下图片及platform.json提供给模型；model_inputs.jsonl是本地索引，并非千问API请求格式。
truth、meta、batch_config只能用于评测或复现，不可作为盲测输入。
本次未接千问、未调用外部模型、未实现模型输出轨迹；后续需接识别/反演工具并对比真值。
当前所有数据位于同一台本地机器，目录分离不是安全访问控制或真正的盲测封存。

## 语义结构输出

每个成功批量样本自动产生semantic.json，原有meta.json不替换。Schema原文保存在btr_semantic_schema_v1.json。
平台与目标运动参数取params，起终点按实际路径公式计算；阵列方位/CPA与证据行号来自TXT，保持TXT全时段口径及原文件精度。
曲线目标的speed_kn/speed_ms只是输入标称值，不表示曲线实际速度；该限制在目标warnings中注明。
推论带value/method/rule_id/confidence；深度、类型、威胁无证据时为null，不把真值混作模型预测。
置信度是规则人工设定值，不是经过统计校准的概率。距离按最小CPA分档、穿越按CPA<0.5km定义，不等同初始距离或几何交叉。
语义文件在样本根目录（不在input），也不写入model_inputs.jsonl。它含答案，不能作为盲测模型输入。
内置校验器覆盖本Schema实际使用的所有断言关键字，遇到不支持的关键字报错；不是完整draft-07通用实现。不依赖额外pip包。
补生成旧批量样本：`python btr_semantic.py --root btr_out`，会同步meta/manifest哈希，跳过活动批次；原有声呐图不修改。
服务重启后可以查询磁盘历史批次，未完成批次标记为中断，不自动续跑。

## 接口

- POST /batch/start：`{count, mode, seed, percent, params}`；返回`{ok,job}`；无效参数返回400。
- GET /batch/status/<id>：返回状态，成功/失败数、当前样本与文件索引；不存在404。
- POST /batch/stop：`{id}`；停止后续样本。
- GET /batch/files/<批次>/<相对文件路径>：查看/下载文件，限制在btr_out内。
- POST /run：原单次接口保留；新增可选SHOW_TRUTH_OVERLAY（默认true）、EXPORT_TRUTH（默认false）。

所有HTTP仅适用于本机可信使用，不要暴露到公网。
