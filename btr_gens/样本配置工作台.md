# 自定义样本配置工作台

启动现有 `btr_gui_server.py`，两种方式通过页面顶部标签切换：

- **自动随机**：http://127.0.0.1:8765/studio ，填写目标样本数量、每个样本的平台数量和目标数量，点击开始。
- **自定义配置**：http://127.0.0.1:8765/studio/advanced ，保留所有维度、参数范围和数量策略。

原单次仿真和 S01～S16 功能保持不变。自动方式的调度在新增 `btr_auto.py` 中，非自动模式直接交给原批量管理器；原 BTR 仿真函数不修改。

## 自动随机方式

样本数量指成功的完整仿真样本数，不是图片数或水下目标数。平台数量为 1～8，默认 1；每个样本的目标数量为 1～12，默认 2。同一批中的每个样本使用设定的平台数量和目标数量；多个平台共同观察同一组目标，不把目标数乘以平台数。每批使用新的随机种子；近/中/远、静止/移动、直线/折线/曲线和噪声条件组合打乱后循环覆盖；每次实例的具体数值重新采样。固定600秒、时间步长1秒、方位步长0.25°。

结果区按平台预览最新成功样本的三种图：轨迹图（`btr_A_track.png`）、舷侧阵 BTR（`btr_A_hull.png`）、拖曳阵 BTR（`btr_A_tow.png`）。轨迹图仍存于 `truth/`，不写入模型输入索引。

失败后换一组参数补生成，只有成功样本计入目标总数。成功目录连续编号 `sample_0001`～`sample_N`，失败尝试另放 `failed_attempts/`，不会混入模型输入索引。补生成最多 `max(10, ceil(N×20%))` 次额外尝试，连续失败5次会提前结束并显示未达标原因；不把数量不足标成完成。主动停止保留当前结果，不自动补齐。

两种页面共用一个任务管理器，同一时间只运行一个批次；切换页面和刷新不会重复提交。自动任务的成功数量/进度在两种页面中保持同一口径。

`POST /batch/start` 请求格式为 `{"mode":"auto","count":目标样本数量,"platform_count":平台数量,"target_count":每个样本的目标数量}`，省略 `platform_count` 时默认 1，省略 `target_count` 时默认 2。所有自动参数和种子保存在 `batch_config.json`；该文件仍能导入自定义配置页检查或复用。

以下是自定义配置方式的说明。

## 使用顺序

1. **选择维度**：每行至少勾选一项。平台数量 1～8、平台静止/匀速移动、目标数量 1～12、初始距离近/中/远、直线/折线/曲线、低/中/高噪声，共六个维度。右侧实时计算组合数量及前六个条件预览。
2. **设定范围**：修改各距离档、航速、平台航向、平台相对 A 的间距、拖曳阵后置距离。展开高级参数，设置信号强度、亮带宽度、噪声、杂波、出现/消失时间比例。每个区间可设最小值等于最大值以固定数值。
3. **设定采样**：时长、时间步长、方位步长和参考经纬度。较短时长、较粗步长适合先检查配置。网格超过500万或可见窗口无法保证包含采样点时，页面拒绝提交。
4. **选择数量策略**：
   - 指定总量：使用种子打乱全部组合，先不重复覆盖，覆盖一轮后循环；同一组合的每次实例独立采样。均衡指完整组合的次数差最多1，不保证未覆盖完一轮时每个单独维度的边际数量完全相等。
   - 每组合固定份数：枚举全部所选组合，每组合生成指定份数。
   - 自定义工作台单批最多10,000个样本；原批量入口仍为最多1,000个。
5. **开始生成**：查看实际成功、失败和当前样本。停止操作等待当前样本完成，保留已生成结果。刷新页面恢复当前任务/本浏览器最近任务；服务重启后旧任务标记中断，不自动续跑。
6. **保存配置**：表单自动保存到本浏览器。导出 JSON 便于复用，导入时经过后端验证；任务的 `batch_config.json` 也能直接导入。

## 数据定义

- 所有平台观察同一组目标；选择3个平台、5个目标，指3个平台共同观察5个目标，而非15个目标。
- 当前平台运动状态作用于本样本的全部平台；各移动平台独立采样航向和速度。
- 同一样本的全部目标使用同一距离档、路径类型；具体方位、速度、亮度等分别随机采样。当前不配置同一样本内近/远混合或不同路径类型混合。
- 距离档定义为 **t=0时目标相对平台A的球面距离**。不是CPA、全程距离或相对所有平台的距离，不承诺穿越条件。
- 目标路径从全局t=0运动，出现时间只控制可见窗口。
- 曲线由基准匀速漂移加横向正弦摆动组成；所填目标航速是基准漂移航速，瞬时速度随曲线变化。折线目标按给定航速经一个折点转向。
- 目标初始方位与目标路径方向独立在0～360°内采样；平台航向使用表单区间。
- 噪声区间是模拟器数值标准差，不是经过物理标定的SNR。
- 当前仿真器不支持安全跨日期变更线的经度插值；工作台按配置最大运动范围提前拒绝可能跨±180°或接近极点的配置，不自动改变坐标或输出错误轨迹。
- 同一配置、种子与运行环境复现数值；时间戳、输出目录、TXT生成时间及文件哈希不承诺相同。

## 输出

继续写入 `btr_out/batch_<时间>_<唯一编号>/`，不同批次不覆盖：

- `batch_config.json`：完整范围、种子、数量策略。
- `manifest.json`：真实状态、成功/失败、每样本的组合条件和SHA256。
- `model_inputs.jsonl`：仅成功样本的图片及平台信息索引。
- `sample_0001/input/`：每平台两张无真值叠加的 BTR 图片及 `platform.json`（不含方位步长 `DB_STEP`）。
- `sample_0001/truth/`：轨迹图、TXT和逐时刻真值。
- `sample_0001/meta.json`：实际数值参数；`params._studio`保存组合ID、条件、轮次和距离口径。
- `sample_0001/semantic.json`：仿真参考语义，非外部模型预测。

只有 `input/` 下文件作为模型输入；真值、元数据和语义标注不混入模型输入索引。配置预览不创建样本或目录。

## 接口与验证

- `GET /studio`、`GET /studio/defaults`
- `POST /studio/preview`：提交工作台配置，返回标准化配置、组合/样本/图片数量及前六个条件。
- `POST /batch/start`：`{"mode":"custom","studio":配置对象}`，沿用现有状态、停止、文件接口。
- `GET /batch/active`：当前服务内活动任务，用于刷新和提交响应不确定时恢复；不会重新发起生成。

从Python代码目录运行 `python -m unittest discover -v`；从仓库根目录运行 `node work/test_batch_ui.cjs`、`node work/test_studio_ui.cjs`。无需增加第三方依赖。
